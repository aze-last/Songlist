# Bug Hunter (DEPRECATED)

> **DEPRECATED (kit v1.3.0).** Use `skills/diagnosing-bugs/` instead. This folder is archived
> for reference only and is no longer registered in the coordinator roster.

Systematically debugs and fixes a bug using standard debugging techniques.

## What It Does

- Reproduces the bug
- Traces execution flow
- Identifies the root cause
- Fixes the bug
- Adds tests to prevent regression
- Documents the bug

## Usage

```
Use @bug-hunter to fix the login timeout issue
```

The skill will systematically debug and fix the problem.
